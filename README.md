# Rift Academy

League of Legends tips and guides for every level: fundamentals, role guides, champion guides with current-patch
builds, a tier list, a "what changed this patch" page, a learning path with saved progress, a glossary, and practice
tools (last-hit trainer, objective timers, quiz, role picker, draft practice, map quiz, matchup lookup, game plan
builder, wave simulator, ability icon quiz, champion pool builder), a page for every finished item and rune, and
glossary pop-ups on jargon inside guides.

Live: https://avielraz123.github.io/rift-academy/

Plain HTML, CSS and JavaScript. The site needs no build to work: open `index.html` in a browser and every page renders
from `#/route` links. For the published site, `tools/build-pages.js` also pre-renders every page into its own file
(`guide/wave-management/index.html`, …) so search engines can index each page and shared links show a preview.

## Structure

| Path | What it is |
|---|---|
| `index.html` | Page shell and the pre-rendered home page; loads everything |
| `css/style.css` | All styles (dark theme by default, light theme toggle) |
| `js/app.js` | Router (real paths on the web, `#/route` from disk) and pages |
| `js/tools/*.js` | The practice tools |
| `js/data/guides-*.js`, `roles.js`, `champs-*.js`, `champ-roles-*.js`, `champ-picks.js`, `glossary.js`, `draft-scenarios.js`, `map-quiz.js` | Content (format: `docs/content-format.md`) |
| `js/data/patch.js` | Patch number, timers and game facts |
| `js/data/patch-changes.js` | What changed this patch, from the official patch notes |
| `js/data/item-guide.js`, `rune-guide.js` | Buying advice for every finished item and every rune (item and rune pages) |
| `js/data/champ-adapt-*.js` | "Adapt your build": item swaps per champion+role by enemy team (tanky, squishy, AD, AP, healing, CC) |
| `js/data/comp-tags.js` | Champions with strong healing or heavy crowd control (Game Plan Builder) |
| `js/data/matchups-extra-*.js` | Extra researched lane matchups (with win rates) added to each guide's own list |
| `js/data/builds.js` | Builds and tier list (generated by `tools/gen-builds.js`) |
| `js/data/dd.js` | Champion, item, rune and summoner data from Riot's Data Dragon (generated by `tools/gen-dd.js`) |
| `js/data/abilities-all.js` | Every champion's ability names and icons for the ability quiz, loaded only by that tool (generated by `tools/gen-dd.js`) |
| `guide/`, `champion/`, `role/`, `tools/*/`, …, `404.html`, `sitemap.xml` | Pre-rendered pages (generated by `tools/build-pages.js`; don't edit) |
| `og.png` | Default image for link previews |
| `fonts/` | Self-hosted Inter and Cinzel fonts (SIL Open Font License, licenses included) |
| `tools/check-content.js` | Validates all content: `node tools/check-content.js` |
| `tests/smoke.html` | Opens every page in a phone-sized frame and reports problems |

Note: the `tools/` folder holds both the build scripts (`tools/*.js`) and the pre-rendered Tools pages
(`tools/index.html`, `tools/<tool>/index.html`), because the site's Tools section lives at `/tools/`.

## Updating for a new patch

1. `bash tools/download-dd.sh /tmp/dd` downloads the latest Data Dragon data (and the ability kits of every guided
   champion), then `node tools/gen-dd.js /tmp/dd` rebuilds `js/data/dd.js`.
2. Research the new builds for every champion+role that has a guide (keys of `RA.builds`) and the mid/bot tier
   lists, and update the JSON files in `research/` (shape documented at the top of `tools/gen-builds.js`).
   Then run `node tools/gen-builds.js research/research-*.json`.
3. Update `js/data/patch.js` (patch number, `updated`, timers, facts) if anything changed.
   Then refresh the 16 guides in `js/data/matchups-extra-*.js` whose `source` patch is oldest (all 64 rotate over
   four patches): new win rates from op.gg, move or replace matchups that flipped, keep about 8 hard and 8 easy, fix
   tips that no longer fit, and set `source` to the new patch.
4. If items or runes changed, update `js/data/item-guide.js` / `rune-guide.js` (check-content warns about missing or
   removed ones) and fix `js/data/champ-adapt-*.js` entries that name removed items or no longer match the build.
5. Rewrite `js/data/patch-changes.js` from the official patch notes on leagueoflegends.com (shape in
   `docs/content-format.md`). Copy numbers exactly; write the summaries in plain words.
6. `npm install` (once), then `node tools/build-pages.js` to re-render every page.
7. Run `node tools/check-content.js` and fix any errors (for example removed items). Then open `tests/smoke.html`
   in a browser (or headless Chrome/Edge with `--dump-dom`) to check every page. Served over http (for example
   `python -m http.server` in the folder above this one, then `http://localhost:8000/rift-academy/tests/smoke.html`)
   it also checks every pre-rendered page.

## Search engines

`sitemap.xml` lists every page. To get the site into Google faster, add it in Google Search Console
(https://search.google.com/search-console) as a URL-prefix property for `https://avielraz123.github.io/rift-academy/`
and submit `sitemap.xml`.
